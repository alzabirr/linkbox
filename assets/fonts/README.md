# Fonts

All three are free Google Fonts (SIL Open Font License). Download them and put the
files in this folder with exactly these names (they match `pubspec.yaml` in docs/THEME.md):

| File | Download from |
| --- | --- |
| `BricolageGrotesque-Variable.ttf` | https://fonts.google.com/specimen/Bricolage+Grotesque (Get font → Download, use the variable .ttf) |
| `Outfit-Variable.ttf` | https://fonts.google.com/specimen/Outfit |
| `HindSiliguri-Regular.ttf` | https://fonts.google.com/specimen/Hind+Siliguri |
| `HindSiliguri-SemiBold.ttf` | same zip |
| `HindSiliguri-Bold.ttf` | same zip |

Also copy each font's `OFL.txt` here (it's in the zip) — the license asks you to ship it.

Claude Code can do this for you in milestone M0, e.g. from
https://github.com/google/fonts/tree/main/ofl (folders `bricolagegrotesque`, `outfit`, `hindsiliguri`).
